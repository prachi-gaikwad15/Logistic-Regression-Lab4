# Titanic Survival Prediction using Logistic Regression

## Lab 4

### Objective
To implement Logistic Regression using the Titanic dataset and predict whether a passenger survived or not.

### Dataset
Titanic Dataset

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

### Machine Learning Model
Logistic Regression

### Model Performance
- Training Samples: 712
- Testing Samples: 179
- Accuracy: 81.01%

### Files in this Repository
- `Logistic_Regression_Lab4.ipynb` – Jupyter Notebook containing the complete implementation
- `Logistic_Regression_Lab4.html` – HTML version of the notebook
- `Logistic_Regression_Lab4.pdf` – PDF version of the lab
- `train.csv` – Titanic training dataset

### Conclusion
The Logistic Regression model was trained on the Titanic dataset and achieved approximately 81.01% accuracy on the test data.
